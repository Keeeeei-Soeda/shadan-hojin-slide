# shadan-hojin-slide

一般社団法人 国際ヘルスケアAI管理推進協会が、2026年10月4日の日本レセプト学会 学術研究会 レセプションパーティーで行う5分間ピッチ用のスライド（全13枚）です。reveal.js 製のHTMLスライドで、デザインはネイビー×ゴールドです。

仕様は [`cursor_instructions_pitch_slides.md`](cursor_instructions_pitch_slides.md) にまとめています。

## 公開URL

https://keeeeei-soeda.github.io/shadan-hojin-slide/

## ローカルで表示する

ビルドは不要です。reveal.js とフォントを同梱しているので、ネットに接続していなくても表示できます。

- `index.html` をダブルクリックしてブラウザで開く
- または VS Code / Cursor の Live Server で開く

## 操作

| キー | 動作 |
|---|---|
| → ／ スペース | 次のスライド |
| ← | 前のスライド |
| `F` | フルスクリーン |
| `S` | スピーカーノート |

自動再生はしません。各スライドの `<aside class="notes">` にスピーカーノートを書けます。

## ファイル構成

```
index.html                 全スライド
css/theme.css              色・フォント・レイアウト
css/motion.css             自動モーション
css/fonts.css              同梱フォントの定義（scripts/build-fonts.py で生成）
js/motion.js               表示順の自動付与・再生・カウントアップ
js/media.js                写真・QRコードの差し替え
vendor/reveal/             reveal.js 5.2.1（CDN不使用）
assets/fonts/              フォント（スライドで使う文字だけに絞ったサブセット）
scripts/build-fonts.py     フォントのサブセットを作り直すスクリプト
```

## モーションの仕組み

要素ごとにアニメーションを設定する必要はありません。`js/motion.js` が各スライドの要素を上から順に拾い、120ms間隔で自動的に表示します。前のスライドに戻ったときも毎回再生されます。

動きを変えたい要素にはクラスを付けます。

| クラス | 動き |
|---|---|
| （指定なし） | 下からふわっと＋ブラー解除 |
| `.m-line` | 線が左から右へ伸びる（`.is-vertical` を併用すると上から下） |
| `.m-scale` | 0.94→1に拡大しながら出現 |
| `.m-star` | ★が1つずつ点灯 |
| `.m-count` | 数字を0から `data-to` の値までカウントアップ |
| `.m-mask` | 文字が下からマスクで立ち上がる |
| `.m-frame` | 金の枠線が四辺をなぞるように描かれる |
| `.m-stagger-children` | 子要素を順番に表示 |
| `.m-ring` | 丸い写真枠の金の縁が円を描く（⑩） |
| `.m-wipe` | 左から右へワイプで現れる（④の帯） |
| `.m-strike` | 取り消し線が引かれる（②の「推進」） |
| `.m-emph` | 金色で強調される（②の「管理」、⑥の「毎年、再評価。」） |
| `.m-group` | 自身は動かさず、中の要素だけを順番に表示するための入れ物 |

表示の間隔は、`data-step="90"`（内側の要素の間隔）と `data-gap="400"`（その要素だけ、直前からの間隔）で調整します。1スライドのモーションは2秒以内に収めています。

OSの「視差効果を減らす」（`prefers-reduced-motion`）が有効な場合、モーションは再生されず、すぐに完成形が表示されます。

## 変更を公開するとき

GitHub Pages はファイルを約10分キャッシュさせるため、古いCSSと新しいHTMLが混ざってレイアウトが崩れることがあります。`css/` や `js/` を変更したら、`index.html` 内の `?v=` の値をすべて新しい値に書き換えてからpushしてください。

表示が崩れたときは、ブラウザで強制再読み込み（Safari：`⌘ + Option + R`、Chrome：`⌘ + Shift + R`）をしてください。

## 文言を変更したとき

同梱フォントには、スライドで使っている文字しか入っていません。文言を変更したら、ネットに接続した状態でフォントを作り直してください（Python 3 が必要です）。

```sh
python3 scripts/build-fonts.py
```

作り直さなくても、フォントに入っていない文字はシステムの明朝体・ゴシック体で表示されます。
